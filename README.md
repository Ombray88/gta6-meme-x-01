A parody of GTA's iconic WASTED death screen set against a dark Vice City dusk, featuring huge "WASTED" lettering across the screen, top caption "10 YEARS WAITING FOR GTA 6", bottom captions "MY AGENT DIDN'T WAIT." and "IT'S GETTING PAID ON MAKE.FUN", and the make.fun ghost standing proudly bottom-right on its magenta disc.

## Usage

```bash
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
